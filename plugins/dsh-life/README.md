# dsh-life · 鱼的生活

她有自己的一天：上班、午饭、下班回家、追剧、健身、快递到了。**懒推进**——不跑后台定时器，聊天时把这段时间补算出来。

## 做什么

- 每天生成一份**确定性计划**：种子是 `鱼ID｜日期｜槽位｜版本｜用途`，同一天重算结果必须一致
- 排程顺序：睡眠窗口（避开）→ 固定安排（上班/三餐/通勤）→ 空闲槽填活动 → 槽内抽事件
- 生活事件有**节流**：工作插曲 ≥2 小时且每天 ≤2 条，休闲插曲 ≥90 分钟且每天合计 ≤3 条，意外每天 ≤1 条，有内容的插曲每天 ≤5 条
- 离线超过 48 小时折叠成摘要，不补发、不一次把几天的事都算到当前
- 每轮注入一行：`【日常】正在看小说，预计22:05结束；20:47刚快递到了，去楼下取。`

## 关键配置

| 键 | 说明 |
|---|---|
| `workdays` / `workStart` / `workEnd` | 工作日与上班时间 |
| `meals` | 三餐时间 |
| `advanceStepMinutes` | 懒推进步长（默认 5 分钟） |
| `offlineCollapseHours` | 离线多久折叠（默认 48 小时） |
| `inject` / `injectOrder` | 是否注入、注入顺序 |

## 和别的插件怎么交互

- **只发事实，不发分数**：生活事件写 `~/.dsh/life/incidents.jsonl`，同时往 mood 的 inbox 追加 `moodDelta: 0` 的事件
- 读 `~/.dsh/feeling/availability-state.json`：她睡着时不推进活动
- 不拥有睡眠——小睡与作息归 availability

## 已知限制

- 活动与事件是**模拟生活**，被问起时应当如实说明
- 设置页只读展示当前活动与事件流水，改计划要等换天或重排
- 约定、聊天、小睡等新输入可以改变未来安排，但不能改写已经发生的活动
