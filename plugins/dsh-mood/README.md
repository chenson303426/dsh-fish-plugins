# dsh-mood · 鱼的心情

一条鱼的整体状态：`mood` 0~100 + 七个情绪维度，按半衰期衰减，每轮给模型一小段状态提示。

## 做什么

- 每轮结束调一次模型判断：这一轮她遇到的事，让 mood 和维度怎么变
- 也可以被外部事件直接改：`POST /dsh-mood/apply`，或往 `~/.dsh/mood/inbox.jsonl` 追加一行
- 注入**绝不出现数字**：只有等级、倾向，以及最多两句情绪倾向
- 同一变化只注入一次；置信度不足、当天额度用完都不注入
- 生成内心旁白（`inner`）时只喂它**事实**，不许补充没发生的细节；写不出来就退回代码模板

## 关键配置

| 键 | 说明 |
|---|---|
| `moodBase` / `moodFloor` | 心情基线与下限 |
| `decayHalfHours` | 衰减半衰期（默认 14 小时） |
| `injectConfidence` | 低于这个置信度不注入 |
| `injectPerDay` | 每天最多注入几次 |
| `sigMood` / `sigDim` | 多大的变化才算“值得告诉她” |
| `naturalInject` | 是否让模型写那句内心旁白 |

## 和别的插件怎么交互

- 收 `sulk`、`feeling`、`life` 的事件（`inbox.jsonl`）
- 七个维度：开心 / 踏实 / 甜蜜 / 心疼 / 担心 / 难过 / 吃醋；渲染时取绝对值最大的两个，各给一句**倾向**（不是命令）
- `GET /dsh-mood/state` 给别人读状态；`GET /dsh-mood/preview` 看下一轮会注入什么

## 已知限制

- 判断标准里写死了“不因用户惹她/不回消息而掉 mood”——那归 feeling
- 心情和情绪维度目前只影响注入文案，**不影响工具调用或行为决策**
- 状态改动后需要重启才完全生效（内存状态）
