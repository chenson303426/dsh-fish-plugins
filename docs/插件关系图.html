三条规矩（和 Codex 定的）：

  1. life 只发事实，不发分数。它说“14:20 开始打游戏”“被领导训了”，mood 和 feeling 各自评估，不互相拿对方的分数当新证据（否则会正反馈）。
  2. availability 是唯一写入者。作息区间只由它生成，sulk / mood / life 都来查，不自己算一套。
  3. 消费是 at-least-once。先落库、再推进 offset；重启补消费旧观察，但过期的主动消息绝不补发。

现在实际的连接：sulk 沉默观察 → mood/inbox.jsonl → mood、feeling 事件 → mood/inbox.jsonl → mood，mood 每 3 秒读一次。
